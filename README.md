# Smarika Portfolio Site

This folder contains a simple static site that turns your portfolio PDF into a clean public link.

## Files

- `index.html`: landing page with portfolio preview and action buttons
- `styles.css`: site styling
- `assets/Smarika-Shrestha-Portfolio.pdf`: portfolio PDF
- `assets/Smarika-Shrestha-Resume.pdf`: resume PDF

## Best public URL

If you publish this repo to GitHub Pages under the GitHub account `smarika-hub`, the link will be:

`https://smarika-hub.github.io/smarika-portfolio/`

## Quick publish steps

1. Create a new GitHub repo named `smarika-portfolio`.
2. Upload the contents of this folder.
3. In GitHub, open `Settings` -> `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/ (root)` folder.
6. Save and wait for Pages to publish.

## Link formats to paste into applications

Plain URL:

`https://smarika-hub.github.io/smarika-portfolio/`

Markdown:

`[Portfolio](https://smarika-hub.github.io/smarika-portfolio/)`

HTML:

`<a href="https://smarika-hub.github.io/smarika-portfolio/">Portfolio</a>`

Email line:

`Portfolio: https://smarika-hub.github.io/smarika-portfolio/`
